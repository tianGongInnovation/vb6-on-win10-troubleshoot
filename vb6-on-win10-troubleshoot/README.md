# VB6 兼容故障排查（vb6-on-win10-troubleshoot）

VB6.0（Visual Basic 6.0，一种老牌编程工具）在 Win10/Win11 上启动失败、工程打不开、ActiveX 组件报错等兼容性问题的排查技能——按"先搜现成解，再动手修"的路径，给出高频原因的现成修复模板。

由 **天工创新坊** 开发维护，许可 **CC BY 4.0**（署名即可自由使用、修改、分发）。

## 有什么用处？

- 覆盖 VB6 类程序最常见的兼容性报错：`VB6EXT.OLB 不能被加载`、意外错误退出、加载项失败、ActiveX 组件错误等
- 给出"先搜哪些关键词 → 搜不到才查什么"的高效排错路径，避免盲目原创分析（实测教训：盲目原创耗 8 小时，搜现成解只要 10 分钟）
- 整理高频原因的现成修复模板：兼容层（AppCompatFlags）、损坏加载项（VBADDIN.INI）、注册表权限、显卡驱动等，照着执行即可

## 为什么要用？

VB6 虽然老，但大量企业内部程序和工业软件仍靠它运转，Win10/Win11 上却常因兼容垫片、注册表权限等问题启动报错。这类问题网上早有现成解，缺的是一条"搜得准、修得对"的路线——本技能把这条路线整理成可执行步骤，让智能体带你一次走对。

## 如何用？

1. 本技能是为 WorkBuddy 等智能体（Agent）准备的：安装到智能体的技能目录后，直接说"VB6 启动报错，帮我排查"，智能体会按技能流程执行
2. 也可人工阅读本仓库 `SKILL.md`，按步骤自己排查
3. 核心顺序：先并行搜索报错原文（中英文）→ 命中高频原因按模板修复 → 搜不到再深入查注册表/抓包

## 有问题怎么办？

- 修复后仍报错 → 按 SKILL.md"第三步"逐项排除（HKLM 注册表、显卡驱动 OpenGL 老路径等）
- 报错信息不在本技能覆盖范围内 → 把报错原文发给智能体，按"第一动作先搜索"的方法处理
- 问题反馈：本仓库 Issues（优先）或联系邮箱 gouzhongwu@vip.qq.com
